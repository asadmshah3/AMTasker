## [1.0.0] - 2026-11-10

First public release.

### Added

- Logger page (the start page): hours logged today, yesterday and this week with progress rings; 24-hour timelines
  with hover details; notepad with optional link to a `.txt` file; priorities matrix; countdown timer with
  notification; large "Now" card. Sections can be shown, hidden and reordered.
- Logging at a glance: green ▶ / red ■ strip under the tabs, matching status bar and browser tab icon.
- Timer with _Stop & log_, _Stop at…_ (by end time or duration), discard, and _What now?_ work notes.
- _Log this time_ for time you forgot to log.
- Today page: focus tasks, planned minutes, marking, end-of-day shutdown, deadlines, backlog.
- Tracker grid, weekly Review and TimeSheet tabs (hidden by default).
- Colour themes (Classic, Ocean, Forest, Sunset, Grape, Rose), light and dark mode, adjustable page width.
- Profiles with optional PIN.
- JSON backup and restore, CSV export.
- User guide with screenshots.
